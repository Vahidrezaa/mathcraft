# docs-pack — مستندات آفلاین دوزبانه (P5)

مستندات درون‌اپ: صفحات doc دوزبانه برای هر تابع رجیستری (~۲۳۰ تابع — سند ۰۳
بخش ۱۲)، درس‌های مفهومی ۵ دقیقه‌ای (سند ۰۱ F-10.3) و snippet gallery.

- فرمت منبع: Markdown + JSON index (سند ۰۲ بخش ۶)
- تبدیل به باندل offline با FTS5 برای جست‌وجوی سراسری (سند ۰۶ §7.5)
- هر مثال باید دکمه «اجرا در کنسول» داشته باشد (F-9.2)
- در P5 پر می‌شود؛ ساختار ابزار تولید در سند ۰۸ بخش ۷ آمده است
