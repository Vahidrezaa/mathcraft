## ۱. MathCraft چیست؟

MathCraft یک **نرم‌افزار محاسبات مهندسی آفلاین، موبایل‌فرست و متن‌باز** است که جایگزین MATLAB برای دروس ترم ۱ و ۲ رشته‌های مهندسی می‌شود: ماتریس و جبر خطی، حسابان، فیزیک، معادلات دیفرانسیل، آمار و روش‌های عددی. موتور محاسباتی به زبان **Rust** نوشته می‌شود (سرعت نزدیک C، امنیت حافظه)، رابط کاربری با **Flutter** ساخته می‌شود (حس کاملاً نیتیو، ۶۰fps) و خروجی نسخه اول یک **APK آفلاین برای اندروید** است.

وعده اصلی به کاربر: *«کل توان محاسباتی یک نرم‌افزار حرفه‌ای، همیشه در جیب تو — بدون اینترنت، بدون لایسنس، بدون اشتراک.»*

## ۴. اصول غیرقابل‌مذاکره (Non-Negotiable Principles)

۱. **آفلاین مطلق:** هیچ قابلیتی به اینترنت وابسته نیست؛ اپ حتی مجوز `INTERNET` نمی‌گیرد. این یک مزیت امنیتی و حریم خصوصی است که در سند PRD مستند می‌شود.
۲. **هرگز UI را بلاک نکن:** هر محاسبه سنگین روی thread pool رست انجام می‌شود؛ UI همیشه زیر ۱۶ms به تعامل پاسخ می‌دهد.
۳. **صحت قبل از سرعت:** جواب اشتباه سریع، بی‌ارزش است. هر الگوریتم قبل از بهینه‌سازی، با Golden Tests اعتبارسنجی می‌شود.
۴. **حس نرم‌افزار واقعی:** هر جا راه‌حل «وب‌سایتی/دم‌دستی» با «نیتیو/حرفه‌ای» رقابت می‌کند، دومی انتخاب می‌شود — حتی اگر گران‌تر باشد. ایموجی هرگز به‌عنوان آیکون UI استفاده نمی‌شود؛ مجموعه آیکون اختصاصی «Craft Icons» (سند ۰۶ بخش ۲.۵) تنها مرجع آیکون محصول است.
۵. **شکست صادقانه:** اگر CAS نتوانست انتگرالی را حل کند، صادقانه اعلام و راه‌حل عددی پیشنهاد می‌شود؛ هرگز نتیجه اشتباهِ مطمئن‌نما تولید نمی‌شود.

## ۵. محدوده نسخه ۱.۰ (Scope) در یک نگاه

**در محدوده (In Scope):**
- زبان اسکریپت سازگار با MATLAB (زیرمجموعه دقیق ترم ۱-۲ — سند ۰۳)
- ماتریس/جبر خطی کامل برای دروس پایه + اعداد مختلط + چندجمله‌ای‌ها
- روش‌های عددی: ریشه‌یابی، انتگرال‌گیری عددی، درون‌یابی، برازش، ODE (RK45)
- آمار توصیفی و توزیع‌های پایه
- رسم ۲D (خط، پراکندگی، میله‌ای، هیستوگرام، قطبی، subplot) و 3D (surf، mesh، plot3، contour)
- CAS کامل: simplify، diff، int، limit، series، solve، dsolve (زیرمجموعه) با رندر LaTeX
- IDE موبایلی: کنسول REPL، ادیتور با هایلایت و autocomplete، بازرس متغیرها، کیبورد ریاضی
- مستندات آفلاین دوزبانه با مثال‌های قابل اجرا
- خروجی: APK آفلاین اندروید (minSdk 24) + انتشار در GitHub و F-Droid

**خارج از محدوده (Non-Goals) برای نسخه ۱:**
- Simulink یا هر مدل‌سازی بلوکی، GUI Builder، کدجنریشن C/C++
- تولباکس‌های تخصصی (کنترل، پردازش سیگنال پیشرفته، یادگیری ماشین، تصویر)
- Live Scripts (`.mlx`)، MEX، اجرای سروری/کلود، همکاری چندنفره
- iOS و دسکتاپ (در معماری پیش‌بینی شده، در نقشه راه بعد از v1.0)

## ۶. تعریف موفقیت (Success Criteria)

- **صحت:** بالای ۹۵٪ تکالیف نمونه ترم ۱-۲ (کورپوس ۲۰۰ اسکریپت واقعی) با خروجی منطبق بر Octave (تحمل خطای نسبی 1e-9) اجرا می‌شوند.
- **عملکرد:** شروع سرد زیر ۲ ثانیه، ارزیابی عبارت ساده زیر ۵ms، معکوس ماتریس ۱۰۰۰×۱۰۰۰ زیر ۱۲۰ms روی گوشی میان‌رده.
- **تجربه:** Crash-free ≥ ۹۹.۵٪ در بتا؛ نمره کیفیت طراحی در بازبینی مستقل بالای ۸/۱۰.
- **پذیرش:** ۱٬۰۰۰ نصب فعال در ۳ ماه اول انتشار از GitHub / F-Droid / بازارهای ایرانی.
