# سند ۰۵ — طراحی موتور سمبلیک (CAS Engine)

> **MathCraft** | کرِیت `mc-cas` | نسخه 1.0
> کاربر CAS کامل را انتخاب کرده است (تصمیم D-05). این سند نشان می‌دهد «CAS کامل» چطور **قابل تحویل و قابل تست** می‌شود: با معماری سه‌لایه، فازبندی سه‌مرحله‌ای و سیاست صداقت در شکست.

---

## ۱. مأموریت و مرزهای CAS

**مأموریت:** پوشش کامل نیاز سمبلیک ترم ۱-۲: ساده‌سازی، مشتق، انتگرال نامعین/معین استاندارد، حد، سری تیلور، حل معادله/دستگاه، dsolve زیرمجموعه — با نمایش زیبای LaTeX و حساب دقیق گویا.

**قاعده طلایی صداقت:** CAS هرگز «نتیجه حدسی را مطمئن‌نما» ارائه نمی‌دهد. اگر انتگرالی حل نشد: پیام صریح «MathCraft نتوانست حل نمادین بیابد» + پیشنهاد `integral` عددی با نتیجه عددی. قابل اعتماد بودنِ شکست، بخشی از برند حرفه‌ای ماست (اصل ۵ سند ۰۰).

## ۲. درخت عبارت (Sym Tree)

```rust
pub enum Sym {
    Integer(rug::Integer),        // دقیق — GMP
    Rational(rug::Rational),      // دقیق — 1/3 هرگز تبدیل به float نمی‌شود
    Real(f64),                    // ورود فقط از کاربر/عدد غیرگویا صریح
    Symbol(Rc<str>),              // x, y, theta
    Add(Vec<Sym>),                // صاف‌شده (flattened) — بدون تو در تو Add(Add(..))
    Mul(Vec<Sym>),                // صاف‌شده
    Pow(Box<Sym>, Box<Sym>),
    Fn(Rc<str>, Vec<Sym>),        // sin(x), exp(x), log(x), sqrt(x), ...
    RationalFn { num: Box<Sym>, den: Box<Sym> },  // فرم نرمال تابع گویا (داخلی)
}
```

**قواعد ساختاری (Canonical Structure):**
- `Add/Mul` همیشه flat و مرتب با ترتیب کلیدی پایدار (deterministic ordering) — خروجی repeatable.
- ضرب‌ها به (ضریب گویا) × (باقی) نرمال می‌شوند؛ توان‌های همان پایه تجمیع می‌شوند.
- صفر جمع = حذف؛ ۰×X = ۰ **فقط وقتی X تعریف‌شده روی همه دامنه است** (تقسیم بر صفر! قاعده گارد پایین)؛ x¹=x، x⁰=۱ (با گارد).

**حساب دقیق:** همه ضرایب با `rug` (GMP)؛ `Rational` برای تقسیم، `Integer` برای صحیح. سرعت GMP برای اعداد اندازه درس (≤ ۲۰۰ رقم) بسیار فراتر از نیاز است. `vpa(n)` → `Real` با دقت دلخواه در فاز CAS-3 (rug Mpfr).

## ۳. پایپ‌لاین ساده‌سازی (simplify)

سه سطح با انتظارات متفاوت:

### سطح ۰ — Automatic Simplification (همیشه روشن)
هنگام ساخت هر node: جمع/ضرب صاف می‌شود، ضرایب جمع می‌شوند، توان‌های هم‌پایه ادغام، ترتیب کلیدی اعمال. این لایه باعث می‌شود `x+0` همیشه `x` باشد بدون فراخوانی simplify صریح.

### سطح ۱ — Rule-based Rewriting با E-Graphs (کرِیت `egg`)
- قواعد بازنویسی (مجموعه اولیه ~۸۰ قاعده): جابجایی/شرکت‌پذیری، توان‌ها، `exp(log(x))→x` (با گارد)، `log(exp(x))→x` (گارد دامنه)، `sqrt(x)²→x` (گارد)، **اطلاعات مثلثاتی**: `sin²+cos²→1`، `tan=sin/cos`، فرم‌های جمع به ضرب، فرمول‌های زاویه.
- **Equality saturation:** e-graph همه فرم‌های معادل را موازی نگه می‌دارد و در پایان «بهترین» (کوتاه‌ترین با هزینه ترجیحی) استخراج می‌شود. مزیت حیاتی نسبت به زنجیره حریصانه قواعد: به دام مرحله میانی بد نمی‌افتد.
- بودجه: timeout 100ms و سقف node (مثلاً 30k) — عبارت‌های انفجاری graceful می‌شوند.
- گاردهای دامنه: قاعده‌ای که روی بخشی از دامنه غلط است (مثل `sqrt(x²)=x`) بدون گارد `assume` اعمال نمی‌شود — این دقیقاً جایی است که CASهای amateur صادق نیستند؛ ما صادق می‌مانیم.

### سطح ۲ — Normal Forms تخصصی
- **Polynomial Normal Form:** نمایش sparse multivariate (map مرتب از monomial→ضریب). `expand, collect, factor` روی همین فرم.
- **Rational Normal Form:** num/den کوپریم (gcd چندمتغیره: subresultant PRS برای متغیر واحد؛ متغیرهای چندگانه → content+primitive part). `numden, simplify` روی کسرها.

## ۴. مشتق‌گیری (diff)

الگوریتم کلاسیک بازگشتی روی درخت — کامل و قابل اطمینان:
- قواعد جمع/ضرب/کسر/زنجیره/توان (عمومی: `u^v` → `u^v·(v'·ln u + v·u'/u)` با گارد).
- جدول مشتق: exp، ln، log10، sin/cos/tan و معکوس‌ها، sinh/cosh/tanh، sqrt، abs (دیفرانسیل‌پذیری گارد |x>0|→هشدار)، `erf` (P2).
- `diff(f, x, n)` تکرار؛ مشتق جزئی با نگه‌داشتن سایر نمادها.
- **تست:** مشتق، با نمونه‌های تصادفی، دوباره عددی (finite difference با دقت کنترل‌شده) مقایسه می‌شود — property test دائمی (سند ۰۸).

## ۵. انتگرال‌گیری نمادین (int) — پایپ‌لاین پلکانی «Risch-lite»

نسخه ۱ **Risch کامل** (الگوریتم تصمیم نظری) نیست — بلکه پایپ‌لاین عملی زیر است که پوشش دروس را می‌دهد و هر مرحله log و قابل تست است:

```
int(f, x):
 1. پیش‌پردازش: به RNF؛ تجزیه به sum
 2. چندجمله‌ای → مستقیم
 3. جایگذاری u-subception هوشمند: اسکن عوامل برای g با f'÷f راتسینال
    (derivative-divides: اگر f = g^k · h و h شامل g نمی‌شود و k·g' | h')
 4. تابع گویا: Hermite reduction (بخش گویا) + Rothstein–Trager
    (ریشه‌های log از gcd نتیجه‌ای) → خروجی دقیق با لگاریتم‌ها
 5. جدول فرم‌های استاندارد: e^(ax+b)·(ax+b)^n، sin/cos ترکیبی،
    1/(a²+x²)، 1/√(a²−x²)، x·e^(ax)، …  (~۴۰ قالب)
 6. integration by parts + recursion با بودجه عمق ۳ و کش زیرنتایج
 7. تبدیل exp/trig به میدان exp(complex) و تلاش مجدد گویا
 8. شکست صادقانه → پیشنهاد عددی
```

- **معین:** `int(f, x, a, b)` = antiderivative + ارزیابی با continuity check (نقطه پرش/تکیه‌گاه در بازه → بررسی و هشدار؛ مسیر دوم: محاسبه عددی تطبیقی به‌عنوان cross-check).
- **تست مرجع:** مجموعه ۱۲۰ انتگرال استاندارد (Rubi-lite list) با نتیجه معتبر؛ سازگاری صحت با مشتق‌گیری معکوس (d/dx بررسی‌شده = f) — این خودآزمایی دائمی است و هر نتیجه CAS قبل از ارائه به کاربر **به‌طور خودکار با diff تأیید می‌شود** (کیفیت افسانه‌ساز).

## ۶. حد (limit)

- مسیر ۱: تیلور/بسط سری در نقطه (بخش ۷) → حد = جمله ثابت؛ تفکیک ±∞ و عدم‌وجود (جمله‌های نوسانی).
- مسیر ۲: فرم‌های نامعین 0/0 و ∞/∞ → l'Hôpital با بودجه ۳ بار.
- مسیر ۳: جدول حدود کلاسیک (`sin x / x → 1`، `(1+1/x)^x → e`، …).
- مسیر ۴ (fallback): کاوش عددی چندگانه با دقت صعودی + تشخیص نوسان (lim→DNE گزارش می‌شود با «تحلیل عددی: نوسان بین…»).
- `limit(...,'left'/'right')` پشتیبانی کامل؛ گزارش جهت‌دار برای حدهای یک‌طرفه نابرابر.

---

## ۷. سری (taylor)

- `taylor(f, x, a, order)` با مشتق‌گیری تا مرتبه order (سقف پیش‌فرض ۱۰، سقف مطلق ۲۰).
- بهینه‌سازی برای راندمان: بسط Horner-like برای گویاها؛ سری مرکب برای ترکیب توابع.
- نتیجه همیشه + O(x−a)^n نمایشی (در LaTeX: `\mathcal{O}`).

## ۸. حل معادلات (solve)

| ورودی | روش | نتیجه |
|---|---|---|
| خطی تک‌متغیره | جابجایی | دقیق گویا |
| چندجمله‌ای درجه ≤ ۴ | ریشه گویا (RRT) → فرمول رادیکال (درجه ۲/۳/۴: Cardano/Ferrari با ساده‌سازی رادیکال) | دقیق (radical form) |
| چندجمله‌ای درجه ≥ ۵ | **توضیح آموزشی Abel–Ruffini** + ریشه‌های عددی با `roots` | عددی با برچسب |
| گویا | ضرب در مخرج → چندجمله‌ای + چک گارد مخرج≠۰ | با گارد |
| انتقالی تک‌متغیره ساده | جدول وارون‌ها: `exp(ax)=b`، `sin(ax)=b` (شاخه‌ها n-periodic با پارامتر k)، `ln(x)=b` | خانواده حل |
| دستگاه خطی | حذف گاوسی سمبلیک با کسرهای دقیق + پارامتری‌سازی فضای پوچی | دقیق |
| دستگاه غیرخطی ۲ معادله | جایگذاری ساده + solve تک‌متغیره؛ فراتر: پیام صریح «خارج از نسخه ۱» | محدود صادقانه |

`solve` همیشه list برمی‌گرداند؛ `vpasolve` عددی با دقت دلخواه.

## ۹. dsolve (زیرمجموعه دقیق)

- **مرتبه اول:**
  - جداپذیر: `dy/dx = f(x)g(y)` → جداسازی + انتگرال دو طرف (با انتگرال‌گیر پایپ‌لاین بخش ۵).
  - خطی: `y' + p(x)y = q(x)` → فاکتور انتگرال‌ساز.
  - کامل: `M dx + N dy = 0` با چک `M_y = N_x` (+ فاکتور انتگرال‌ساز ساده μ(x) یا μ(y)).
- **خطی با ضرایب ثابت هر مرتبه:** معادله مشخصه (ریشه‌ها با `roots`) → جواب عمومی (ریشه‌های حقیقی/مختلط/تکراری) + **ضرایب نامعین** برای RHS ∈ {چندجمله‌ای، e^ax، sin/cos(ax)، حاصل‌ضرب‌ها} → شرایط اولیه → جواب خصوصی.
- خارج از این زیرمجموعه (مثلاً Bernoulli/Riccati یا ضرایب متغیر): پیام صریح + لینک به روش عددی `ode45`.

## ۱۰. رندر LaTeX (خروجی زیبا)

- نویسنده LaTeX مخصوص ما: اولویت‌دار با پرانتز حداقلی، `\frac` برای گویاها، `\sqrt`، توان‌ها/اندیس‌ها، نام‌های یونانی، `-` unary تمیز، اعشار گویا به‌صورت کسر.
- رندر سمت Dart با `flutter_math_fork` (توالی TeX → ویجت)؛ در کنسول: نمایش تک‌خطی؛ در کارت نتیجه: بلوک مرکزی بزرگ.
- `latex(expr)` رشته TeX خام را هم به کاربر می‌دهد (برای گزارش‌های درس).
- تست: golden string tests برای ۱۰۰ عبارت نمونه + رندر snapshot در Flutter.

## ۱۱. فازبندی تحویل CAS (تصمیم D-05)

| زیرمایل‌استون | محتوا | معیار پذیرش |
|---|---|---|
| **CAS-1** | درخت Sym، حساب دقیق، ساده‌سازی خودکار + egg سطح ۱، `expand/collect/simplify`، `diff` کامل، `subs`، رندر LaTeX | ۱۰۰٪ تست مشتق خودآزمایی؛ مجموعه ۵۰ عبارت simplify مرجع |
| **CAS-2** | `int` پایپ‌لاین کامل (بخش ۵)، `int` معین با cross-check عددی، `solve` (خطی، رادیکال ≤ ۴، انتقالی ساده)، دستگاه خطی سمبلیک | ۱۲۰ انتگرال مرجع ≥ ۹۰٪ + بقیه fallback صادقانه؛ هر نتیجه diff-verified |
| **CAS-3** | `limit`، `taylor`، `dsolve` زیرمجموعه، `vpa`، `assume`، فاکتورگیری عدد صحیح/چندجمله‌ای (Zassenhaus — اگر پیچید، یک‌متغیره square-free + جداسازی) | حدود/سری مرجع ۴۰ مورد؛ dsolve ۳۰ مورد |

**قاعده فاز:** هیچ زیرمایل‌استونی به قبلی وابسته است جز CAS-3 به dsolve داخلی — یعنی پس از CAS-2، محصول بدون CAS-3 هم قابل انتشار است.

## ۱۲. محدودیت‌های اعلام‌شده (Honest Limitations — مستند عمومی می‌شود)

1. انتگرال‌های چندگانه سمبلیک، انتگرال‌های ویژه پیشرفته (Meijer-G)، و Risch کامل → خارج از v1.
2. حل دستگاه غیرخطی عمومی → خارج از v1 (عدد چندشروعی ممکن است در نسخه‌های بعد اضافه شود).
3. ساده‌سازی ترم‌های سمبلیک «زیبا» (فرم گویی انسانی) هدف‌گرا است؛ گاهی نتیجه درست اما غیرزیبا خواهد بود — کاربر همیشه `simplify/expand/factor` را در اختیار دارد.
4. عملکرد: عبارت‌های با >۵۰۰ گره، egg با timeout می‌شوند — پیام شفاف «عبارت بزرگ؛ نتیجه تا حد امکان ساده شد».
